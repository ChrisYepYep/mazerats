# Maze Rats — https://mazerats.net
#
# The archive itself is meant to be found: someone half-remembering a maze
# they walked two years ago should be able to search for it and land here.
# What follows is everything that isn't the archive.

User-agent: *
Allow: /

# The Volter Goldfish picture-glyph sheet, offered in the archive's side
# menu as "Alt Codes". Linked, and deliberately not indexed: it is a tool
# for somebody part-way through naming a room, and it would be a baffling
# thing to land on from a search. It is a window on the homepage now, and
# /glyphs is the homepage with it open; /glyphs.html only redirects there
# (see netlify.toml), and is listed for the links that still point at it.
Disallow: /glyphs
Disallow: /glyphs.html

# The Sorcerer's Atlas is NOT disallowed here, on purpose. It is still being
# drawn and is kept out of search results — but by its noindex (the meta tag
# in wizard.html and an X-Robots-Tag header in netlify.toml), which a crawler
# can only obey if it is allowed to fetch the page. Disallowing it here hid
# that noindex, and a blocked URL other sites link to can still be listed,
# bare. Lift the noindex when it is ready to be found.

# /guess was disallowed while the daily game was an unfinished experiment.
# It is a real feature now — scored, with leaderboards and accounts behind
# it — and a real address people paste at each other, so it is worth being
# findable. It still serves the homepage with the game open, so a crawler
# reaches nothing here it could not already reach at /home.html; and the
# page a searcher lands on is the game itself, which is exactly what the
# link promised. The day's answers are not in the HTML at all — the day is
# dealt on the server and the page is handed the puzzle without them (see
# netlify/functions/_deal.js) — so there is nothing datable for an index to
# go stale on.

# Project tooling and the function endpoints. /tools/ already 404s at the
# edge (see netlify.toml); the functions do not — they are the site's API,
# and answer anybody — but none of them is a page worth indexing, so this
# saves the crawl.
#
# EXCEPT the public reads the archive makes as it loads. A crawler renders
# the page the way a browser does, and a page whose data it may not fetch
# renders empty: the Coming Soon check in home.html reads settings first
# and, unable to, sent the crawler back to the landing page — and past that,
# every /maze, /event and /guides address would have been an archive with
# nothing in it. So these, and only these, are open: the site's switches,
# the mazes, the events, the guides, and the Missing Pieces flags a maze's
# window shows (js/home.js). Every one is a public GET the page makes
# without signing in; the admin routes on the same functions (?full=1, and
# every write) still need a token whatever this file says. article is not
# here: it is POST-only, used by /warren, and nothing reads it on load.
Allow: /.netlify/functions/settings
Allow: /.netlify/functions/rooms
Allow: /.netlify/functions/events
Allow: /.netlify/functions/guides
Allow: /.netlify/functions/dead-ends
#
# And the image CDN. Every share preview's picture is a
# /.netlify/images?url=… address (see netlify/functions/share.js), and so is
# every thumbnail in the archive. X's card crawler and LinkedIn's obey this
# file, so with /.netlify/ disallowed whole, every maze link posted there
# unfurled with no picture, and no room screenshot could be indexed. The
# longer, more specific Allow wins over the Disallow for the crawlers that
# matter (Google, Bing, X, LinkedIn all follow the longest-match rule).
Allow: /.netlify/images
Disallow: /tools/
Disallow: /.netlify/
