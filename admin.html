Read this before you start

This site has no server or database behind it, so there's nowhere for "Save" to actually publish to. Everything you do here is written to this browser's local storage only — it previews live on this device (open the Archive page in another tab to see it), but nobody else will see it. To make a change permanent for every visitor, use Export at the bottom of this page and paste the generated code into js/rooms-data.js / js/events-data.js in the project, then redeploy the site.
